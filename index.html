Nagios Core Monitoring Setup

Infrastructure monitoring with NRPE client

Nagios 4.4.6 Ubuntu 22.04 NRPE Apache2 VirtualBox
▾

Objective

Set up a complete Nagios monitoring environment with a dedicated server VM monitoring a remote client VM via NRPE. Accessible via web UI with authentication.

What was done

  • Configured dual network adapter (NAT + Host-Only) on VirtualBox for VM-to-VM communication
  • Installed and configured Nagios4 with Apache2 on Ubuntu server VM
  • Set up NRPE on client VM to allow remote service monitoring
  • Created all config files manually: nagios.cfg, cgi.cfg, commands.cfg, contacts.cfg, templates.cfg
  • Configured basic authentication via htpasswd for web UI access
  • Resolved 20+ configuration and network errors through systematic troubleshooting

Services monitored

  • PING — host reachability check
  • CPU Load — via NRPE check_load
  • Disk Usage — via NRPE check_disk
  • Current Users — via NRPE check_users

Troubleshooting highlights

  • Resolved VirtualBox NAT-only limitation — both VMs unreachable to each other; fixed by adding Host-Only adapter
  • Fixed Apache/Nginx port conflict causing 404 errors on web UI
  • Debugged missing config files caused by conflict between apt-installed and source-installed Nagios
  • Corrected AuthUserFile path mismatch across 4 Apache config entries
Both hosts UP — PING OK, all services monitored successfully
